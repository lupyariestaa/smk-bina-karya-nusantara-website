# Kredit & Lisensi Gambar

Seluruh foto pada website ini diunduh dari **Wikimedia Commons** dan digunakan untuk
keperluan pengembangan/demo. Foto-foto tersebut berlisensi bebas (umumnya
Creative Commons / domain publik) sesuai ketentuan masing-masing berkas di Wikimedia Commons.

## Sumber

- https://commons.wikimedia.org

## Pemetaan Aset

| Folder                      | Jumlah | Penggunaan                             |
| --------------------------- | ------ | -------------------------------------- |
| `/images/hero/*`            | 9      | Banner/hero halaman                    |
| `/images/jurusan/*`         | 11     | Visual kartu & detail program keahlian |
| `/images/fasilitas/*`       | 16     | Visual fasilitas & galeri              |

| `/images/ekstrakurikuler/*` | 15     | Visual kegiatan ekstrakurikuler        |

## Catatan Penting

- Untuk penggunaan produksi nyata, disarankan mengganti gambar dummy ini dengan
  **foto asli sekolah**.
- Nama file di-generate oleh script `scripts/download-images.ps1`.
- Untuk mengunduh ulang/menambah gambar: jalankan `powershell -File scripts/download-images.ps1`.
